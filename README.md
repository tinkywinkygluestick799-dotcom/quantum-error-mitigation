# Quantum Error Mitigation for NISQ Devices

This repository implements error mitigation techniques for noisy quantum computers.

## Techniques
- Zero-Noise Extrapolation (ZNE)
- Probabilistic Error Cancellation (PEC)
- Readout Error Mitigation

## Key Results
- Combined ZNE + readout reduces error by up to 86%
- PEC achieves 87% reduction at 9x sampling overhead
